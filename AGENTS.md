# Repository instructions

This is a standalone human geography research toolkit. Use the skill under skills/human-geography-research/. Keep real research inputs and outputs under work/ (ignored by Git); examples/ contains synthetic data only.

Do not infer publication readiness from filenames or passing technical checks. Keep observational association distinct from causal identification. Report what ran, what failed, and what remains unverified. Preserve raw inputs and failed attempts. Use explicit user decisions for scientific stage approval; never enter approval on the user's behalf.

Do not import manuscript text, personal paths, credentials, private records or unrelated repositories into this public toolkit. New reusable code must have clear provenance; link external documentation rather than copying third-party implementations.

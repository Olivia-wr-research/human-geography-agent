# 两条英文论文路径 → 人文地理 Agent

这里公开可复用的方法步骤，不公开原稿、私有数据、样本数字、统计结果或内部路径。本次核对了目的地选择的模型解释与预检记录，以及共同作者复现的冻结设计审查与英文改稿交付记录；没有重新拟合原论文。

## 路径 A：流动与目的地选择

```mermaid
flowchart LR
 A[职业记录与来源] --> B[实体与城市匹配]
 B --> C[流动事件及候选集]
 C --> D[事件前关系与城市变量]
 D --> E[事件分层的选择模型]
 E --> F[支持与推断诊断]
 F --> G[候选集和预测敏感性]
 G --> H[图表与论断绑定]
```

1. 界定研究问题：条件于已经观察到流动，哪些目的地特征与选择相关；与“谁会流动”区分。
2. 清理实体和地点，建立事件定义、来源冲突和裁决记录，保留样本流失过程。
3. 以事件 × 候选城市为基本行，每个事件只有一个已选城市；候选集须有事前机会解释。
4. 构造移动前关系经历、既往城市经历和城市特征，保存变换、中心化与时间窗口。
5. 按冻结规格拟合事件分层模型，明确重复个体的推断依赖；事件分层不等于城市固定效应。
6. 检查组内变化、稀疏支持、函数形式和未观测城市吸引力。候选集敏感性不等于 IIA 检验。
7. 对不同调整集合分别解释优势比，不把优势比当成概率百分点。验证划分及重抽样必须说清是否重新拟合。
8. 由权威结果生成表图，按数字类型和出现位置核对摘要、正文、表格与补充材料，再渲染检查。

**迁移到其他人文地理问题：** 就业区位、人口目的地、企业选址等可借鉴候选集和时序审查；具体模型须重新论证，不能直接沿用论文系数或样本。

## 路径 B：合作中断后的共同作者复现

```mermaid
flowchart LR
 A[发表与作者记录] --> B[身份及名单完整性]
 B --> C[中断定义与风险入口]
 C --> D[历史基线与滞后环境]
 D --> E[条件比较及共同支持]
 E --> F[多事件估计与网络依赖]
 F --> G[预设敏感性]
 G --> H[命名对比与条件性结论]
```

1. 将“记录中的共同作者再次出现”与真实关系重新建立区分，检查身份、截断名单和观察窗口。
2. 先明确连续间断年数、基线年份和进入风险集的首年，保留删失、未知事件和非事件。
3. 冻结关系历史与基线状态，环境变量只使用结果发生前可见信息；不同观测状态和环境未必独立。
4. 明确焦点 × 年份等条件比较层，检查多尺度邻居条件及交互对比的共同支持；相同焦点年份不控制伙伴特定可用性。
5. 选择适合每层事件数的条件似然，使用完整协方差计算命名线性组合；不要只读一个交互系数。
6. 对无序关系、共享论文和跨样本连接检查依赖。可见连接整簇不等于完整项目网络，留出也不保证独立。
7. 事先定义支持限制、控制删减和共享记录删减等敏感性，区分模型区间和重抽样区间。
8. 将结论限制为观察性条件关联；支持不足时降低主张，不能以收敛、计算重现或样本规模作为创新证据。

**迁移到其他人文地理问题：** 城市间合作、组织联系、区域知识网络等可借鉴关系测量和依赖审查；年度资料不能伪装成精确时间的事件序列。

## 共用部分与新增部分

| 共用流程 | 本包新增或扩展 |
|---|---|
| 数据与设计冻结、版本和来源追踪 | 独立轻量阶段台账及文件变更检测 |

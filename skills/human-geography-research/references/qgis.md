# QGIS 制图工作流

## 先运行合成演示

1. 在仓库根目录运行 `python scripts/prepare_demo.py --output work/demo`。
2. 安装官方 QGIS，打开一个空白项目。在“插件 → Python 控制台”打开编辑器。
3. 执行下面代码，把 `repo` 改为本机仓库路径，输出目录必须不存在：

```python
from pathlib import Path
repo = Path('/absolute/path/to/human-geography-agent')
namespace = {}
exec(compile((repo / 'scripts/qgis_demo.py').read_text(), 'qgis_demo.py', 'exec'), namespace)
namespace['run_demo'](repo / 'work/demo', repo / 'work/qgis-export')
```

输出包括便携 `.qgz` 项目、两份合成 GeoJSON、300 DPI PNG、PDF 和导出清单。脚本使用独立项目对象，不清空正在编辑的桌面项目。随后打开输出的 `.qgz`，检查标注、图例、比例尺、裁切和 PDF 字体。`visual_review=PENDING` 只有在实际检查后才能更改。

脚本面向 QGIS 3.x / PyQGIS API；已在 GitHub Actions 的 Ubuntu 24.04 / QGIS 3.34.4 环境完成合成数据的导出、纵向页面尺寸与项目重开验证。本机没有安装 QGIS；其他平台/版本与真实研究数据仍需实际测试。不要对普通 Python 执行 `pip install qgis` 来假装获得完整 QGIS 环境。

演示只有虚构城市点和 OD 连接线；线条无箭头，不表达流向，空间距离也不是实测迁移距离。线宽表达权重，图注保留公式。跨日期变更线需专门切分；自流不画零长度线。真实分析应按下列流程另建项目。

## 真实数据到地图

| 步骤 | 操作 | 必须留存的证据 |
|---|---|---|
| 输入审查 | 明确点/面/OD、单位、时间、分母、授权及去标识化 | 数据字典、许可证、哈希 |
| 地理匹配 | 统一稳定 ID，检查重复、未匹配、歧义和一对多 | 匹配率、冲突与裁决表 |
| 几何与坐标 | 检查有效性与 CRS；先确认源 CRS，再重投影 | 源/目标 CRS、处理算法、修复前后变化 |
| 空间连接 | 使用一致边界版本，说明边界点、多重匹配和空结果处理 | 连接前后行数、未匹配清单 |
| 选择图形 | 数量用符号大小；率/强度可用分级面；OD 用连接线 | 指标含义、分母、分类阈值 |
| 设色和尺度 | 缺失与零不同；跨期比较固定阈值和图幅 | 分类参数、固定范围、无数据符号 |
| 版式 | 标题、年份、图例、来源、单位、比例尺及必要指北 | map_manifest.csv |
| 导出 | 保存 `.qgz` 和依赖数据；版式导出 PDF/PNG | QGIS 版本、导出设置、文件哈希 |
| 复核 | 在新会话重新打开项目；查看完整尺寸和印刷尺寸 | map_review.md、未解决问题 |

## 可复用图件路线

**城市分布图：** CSV 的 longitude/latitude 明确为 WGS84 时用分隔文本点图层；错误坐标写入异常表，不静默删点。符号面积而非半径与计数成比例，必要时单独显示零值。

**分级设色图：** 用稳定行政代码连接统计表与授权边界。先排除重复代码和连接膨胀；率的分子分母必须同地区同时间同口径。缺失灰色/纹理，零值进入实际分类。跨期地图共用阈值，不能每年各用分位数再声称绝对改善。

**流动/合作 OD 图：** 城市表与关系表各自审查，连接端点后按稳定 ID 聚合。把净流、总流、双向关系分开；箭头只用于有方向的数据。密集图可采用阈值或抽样，但披露被隐藏的关系和权重。曲线和束化仅为布局，不代表真实路径。

**小多图：** 时间/类型分面共用 CRS、图幅、图例与阈值。自动批量导出前先审一张，并在全部导出后检查缺图、空图和字形。

## 人文地理审查

地图中的边界是数据选择，不是研究结论；记录版本与来源并遵守适用的地图发布要求。空间尺度改变需要敏感性分析；避免把行政区均值解释成每个居民的行为。敏感住址和访谈地点需按研究伦理聚合或移除，不能通过加在线底图泄露。

面积/距离选择适合研究区的投影或椭球测量；全球图不能沿用演示的局部 UTM。修复几何会改变形状，要保留源数据。无底图也应能复现图件，在线图层另记访问日期、许可和外部依赖。

# 证据约束写作与公开复现

先锁定每张表和图的权威脚本、输入哈希、输出文件及参数。把主张连接到结果行、图层或来源页码，再写段落。区分描述、关联、机制解释和因果判断。摘要、正文、表图、补充材料的样本数、单位、模型版本和时间范围必须一致。

结构建议：空间问题与机制 → 文献中的明确缺口 → 数据及测量边界 → 设计与方法 → 结果及不确定性 → 稳健性 → 地理解释和适用范围。不要用宏大议题替代具体贡献；政策含义应限于证据支持的范围。

图表须有标题、单位、分母、样本、时间、来源和必要的限制说明。渲染最终 PDF/Word 并逐页检查跨页表格、裁切、字号、图例和引用定位；没有实际渲染不能声称视觉检查通过。

相关稿件使用共同数据时，建立“问题—样本—变量—模型—结果—文字”重叠矩阵，并按期刊规定披露。作者、资助、伦理、利益冲突和数据可用性声明只能来自作者确认的信息。

公开前使用白名单：只发布拥有相应权利的代码、文档和合成示例。许可证不覆盖上游数据。清除绝对路径、缓存、密钥、邮箱、审稿信和个人轨迹。提供运行命令、环境要求、随机种子、哈希与失败说明；数据不能公开时提供获取条件和合成替代，不伪称完全复现。投稿或发送消息需要对应的明确授权。
